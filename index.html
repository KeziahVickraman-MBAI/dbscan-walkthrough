    CHAPTER 2
    
    From dots to a forecast, one step at a time
    
    
    Five steps turn the simulated sessions into the slide's numbers. Click a step, or use Next. Every figure below is computed live from the run in chapter 1.
    
  
    
  
    

  
  
    
    
    
      
    
        
    Rule
    
        
    no_store_nearby = min distance to any outlet > walk_km
    
        
    Distance is straight-line on the team's map ( km per map pixel; the map is not to scale, so distances are approximate). Nothing is learned here: it is a threshold.

    1 · COUNTNeighbours within εCount the points inside a circle of radius ε around the point, the point included.
    
      
    2 · COREAt least minPts?Then the point is a core point: it sits in a dense pocket.
    
      
    3 · GROWSpread the clusterIts neighbours join the cluster. Any that are core add their own neighbours, and so on.
    
      
    4 · NOISENever reached?Points not reached from any core point are noise: scattered searches, not a pocket worth a store.

    Open a store at the pin. For every user:
    
        
    a = pull(distance to the new store),  s = Σ pulls of today's outlets
    
        
    cups at new store = a / (a₀ + s + a)
    
        
    moved from outlets = s/(a₀+s) − s/(a₀+s+a)
    
        
    net new = cups at new store − moved
    
        
    Sum over all users, then multiply by the cups per dot from step 2.

This page lists every element on the slide, every data point this walkthrough uses, and what would still be needed to run it on real data.
